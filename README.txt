STRIDE CO. footwear shop — updated with realistic shoe concept images

How to run:
1. Keep index.html, script.js, style.css, and the images/ folder together.
2. Open index.html in a modern browser.

The existing product filters, search, sizing, wishlist, bag/cart, promo codes, and checkout interaction remain in script.js. The product visuals are now local WebP image files in images/.
